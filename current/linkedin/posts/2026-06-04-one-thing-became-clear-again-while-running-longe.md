One thing became clear again while running longer agent sessions:"
"Rules are not enough if they cannot stay alive in the workflow."
"You can write strong development rules."
" You can define coding standards, architecture patterns, review expectations, and workflow discipline."
"But over long sessions, rules start to lose weight."
"They get pushed out of context."
" They become outdated."
" They stop matching the current state of the project."
"That is why I no longer see agent rules as static documents."
"They need to become part of the retrieval and context update system."
"For real agent workflows, the question is not only:"
" “What rules should the agent follow?”"
"It is also:"
" “How does the agent keep receiving the right rules at the right time?”
