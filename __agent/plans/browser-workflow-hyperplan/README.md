# Browser Workflow Hyperplan

Háromrétegű koordinációs terv a közös, minden agent által használható browser-runtime és az első Tesco
vertical slice megvalósításához.

- Hyperplan: `hyperplan.plan.md`
- Masterplanek: `master-plans/`
- Subplanek: `subplans/`
- Státusz SSoT: a Hyperplan ledger; az MP/SP fájlokkal minden review során egyeztetendő.

Ez a koordinációs terv a `my-assistant` repóban él. A közös tool specifikációjának/kódjának módosítása a
`LIVE-projects/unblockable-browser-handler-tool` projekt saját authority- és dispatch-folyamatában történik.
